# 用真實 F1 遙測校準車輛物理

`openf1_stats.py` 會從 [OpenF1](https://openf1.org)（免費的歷史資料 API）抓 2024 年新加坡、蒙札、摩納哥三站排位賽的最快圈，算出各速度區間的加速度、煞車減速度和側向 G 值，結果存在 `f1_stats_2024.json`（只存統計數字，不存原始遙測）。

學校網路連不到 OpenF1，所以用 Colab 的 CPU 機器跑：`colab-job --gpu none --name f1data --get /content/f1_stats.json openf1_stats.py`。FastF1 現在需要 F1 TV 付費訂閱才能拿到這些資料，所以沒有用它。

## 校準結果（M4 Max、專業模式、循跡＋防鎖死開啟、平坦柏油）

| 項目 | 真實 F1（2024 排位） | 校準前 | 校準後 |
|---|---|---|---|
| 最高速 | 313～340 km/h | 341 | 309（高下壓力街道賽設定，DRS 另計） |
| 100→200 km/h | 1.9～2.5 秒 | 2.57 | 2.32 |
| 加速 60～180 km/h | 1.3～1.8 G | 1.25 | 1.41 |
| 加速 240～300 km/h | 約 0.6 G | 0.98 | 0.70 |
| 側向 125 km/h | 約 3 G | 2.64 | 2.93 |
| 側向 275 km/h | 5.5～6 G | 5.37 | 5.60 |

調整的參數：輪胎柏油摩擦係數 1.8 → 1.9、下壓力面積 ClA 4.0 → 4.8、阻力面積 CdA 1.43 → 1.6、最大功率 880 → 760 kW。

注意：
- 遙測的位置資料每秒只有約 4 筆，算出的高速彎側向 G 值會被雜訊放大（蒙札、摩納哥出現 8～10 G），比對時以新加坡為準。
- 遊戲的煞車減速度是每秒 240 次的瞬間值，遙測是平滑過的，兩者不能直接比。
- 電腦車和新手煞車輔助的速度規劃仍用比較保守的摩擦係數 1.72；新手規劃另外會保留急彎的曲率尖峰，避免短而急的彎（路口斜切）被平滑掉、輔助來不及煞車。
